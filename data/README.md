# Data

이 폴더는 최종 Neo4j 프로토타입을 재현하기 위한 CSV 데이터를 포함합니다.

- `frameworks.csv`: 3개 Framework
- `domains.csv`: 16개 Domain
- `categories.csv`: 67개 Category
- `controls.csv`: 248개 Control
- `primary_mapping.csv`: 248개 Primary Mapping
- `secondary_mapping.csv`: 58개 Secondary Mapping

Mapping은 연구용 프로토타입의 수동 의미 판단 결과이며 공식 crosswalk가 아닙니다.

Public Repository로 공개하기 전 원 출처 자료의 저작권 및 재배포 조건을 확인하세요.
